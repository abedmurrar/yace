# YACE documentation website

The source of the documentation website, an [mdBook](https://rust-lang.github.io/mdBook/)
published at <https://abedmurrar.github.io/yace/>.

Preview it locally (from the repository root):

```sh
cargo install mdbook --locked --version 0.5.4
mdbook serve site --open
```

`mdbook build site` writes the site to `site/book/`, which is not
committed.

It is deployed by `.github/workflows/pages.yml` on every push to `main`
that changes `site/`, `docs/`, `README.md`, `CHANGELOG.md` or
`CREDITS.md`.

- `src/SUMMARY.md`: the table of contents.
- `src/docs/`, `src/CHANGELOG.md`, `src/CREDITS.md`,
  `src/THIRD_PARTY_LICENSES.md`: one-line includes of the repository's
  files. Edit the originals.
- `src/media/`: screenshots and recordings, generated by `capture/`:

  ```sh
  cargo build --release -p yace -p yace-plugin-tasks
  cargo run --release --manifest-path site/capture/Cargo.toml
  ```
