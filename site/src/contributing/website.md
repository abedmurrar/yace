# This website

**This website is an [mdBook](https://rust-lang.github.io/mdBook/) in the
repository's `site/` folder. Most pages include the Markdown files from
`docs/` and the repository root, so there is one copy of every text, and
the screenshots are generated from the real editor.**

## Preview it

```sh
cargo install mdbook --locked --version 0.5.4
mdbook serve site --open        # rebuilds as you edit
```

`mdbook build site` writes the site to `site/book/` (not committed).

## How the pages are made

- `site/src/SUMMARY.md` is the table of contents.
- Pages under `site/src/docs/` and the changelog, credits and licence pages
  are one-line `\{{#include …}}` wrappers around `docs/*.md`,
  `CHANGELOG.md`, `CREDITS.md` and `THIRD_PARTY_LICENSES.md`. Edit those
  files, not the wrappers. The folder layout matches the repository, so
  links between those files work on the website too.
- The other pages (introduction, getting started, installation, features,
  the plugin guides, performance) are written for the website.

## Screenshots and recordings

Everything in `site/src/media/` is generated by `site/capture/`, a small
Rust program that:

1. creates a demo workspace (a bookshop with a Rust API and a TypeScript
   web app in two Git repositories, plus a deploy folder elsewhere) under
   a temporary home directory, so no real path or name appears;
2. installs the Task Runner plugin into that home;
3. runs the release `yace` binary in a pseudo-terminal of 120 × 34 cells,
   types scripted keys, and waits for text to appear on screen rather than
   for fixed times;
4. emulates the screen with `alacritty_terminal` (the emulator YACE's own
   terminal uses), and writes each screenshot as an SVG, and each
   recording as an asciicast v2 `.cast` file plus an animated SVG that
   plays in the browser without JavaScript.

The scenes are listed in `site/capture/src/scenes.rs`. To refresh the
media after a change to the interface:

```sh
cargo build --release -p yace -p yace-plugin-tasks
cargo run --release --manifest-path site/capture/Cargo.toml          # every scene
cargo run --release --manifest-path site/capture/Cargo.toml -- git   # one scene
```

Captures use the default dark theme (one uses YACE Light), Unicode
glyphs, and the legacy keyboard protocol, so they show the fallback keys a
plain terminal needs. The language server scenes need
`typescript-language-server` or TypeScript 7 on your `PATH`.

## Publishing

`.github/workflows/pages.yml` builds the book with mdBook 0.5.4 and
deploys it to GitHub Pages whenever `main` changes `site/`, `docs/`,
`README.md`, `CHANGELOG.md` or `CREDITS.md`, or when started by hand. It
doesn't run the capture tool: the media are committed.
